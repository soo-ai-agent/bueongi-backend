# data/csv — 오프라인 CSV 입력(최우선 실데이터)

공공데이터포털에서 내려받은 표준데이터 CSV 를 **원천 id 파일명**으로 두면
파이프라인이 fixtures 다음의 최우선 입력으로 사용한다("CSV 기본, API 폴백").

| 파일명 | 원천 | 다운로드 |
|---|---|---|
| `B-1.csv` | 전국 CCTV 표준데이터 | data.go.kr 15013094 |
| `B-2.csv` | 전국 여성안심지킴이집 | data.go.kr 15034535 |
| `B-3.csv` | 전국 지구대·파출소 | data.go.kr 15077036 |
| `B-4.csv` | 생활안전지도 치안안전시설 | data.go.kr 15101889 |
| `C-1.csv` | 서울 가로등 위치정보 | 서울 열린데이터광장 OA-22205 (**파일 전용 — 라이브 API 없음, 이 CSV 가 운영 경로**) |
| `C-2.csv` | 전국 보안등 표준데이터 | data.go.kr 15017320 |
| `C-3.csv` | 서울 보행등(보행신호등) | 서울 열린데이터광장 OA-22354 (**파일 전용**) |
| `D-1.csv` | 전국 안전비상벨 표준데이터 | data.go.kr 15028206 |

- 인코딩은 CP949(EUC-KR)·UTF-8(BOM 포함) 모두 자동 판별한다. 내려받은 파일 그대로 두면 된다.
- 컬럼명은 `sources.yaml` 의 `keyColumns`(위도/경도/관리기관명 등 표준데이터 컬럼)와 일치해야 한다.
- A-4(안심귀갓길)·D-2(자치구 비상벨)는 자치구별 좌표계가 달라 CSV 일괄 매핑 대상이 아니다(manual 유지).
- CSV 가 없으면 data/raw → 라이브 API(키 필요) 순으로 폴백한다.

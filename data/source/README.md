# 원천 CSV 원장

시설 데이터의 **초기 적재본**이다. 여기 있는 파일이 서버 기동 시 메모리 인덱스의 바탕이 되고,
이후 변경분은 API 증분(`clients/client-datagokr`)으로 따라잡는다.

**gzip 으로 저장한다.** 원본 합계 97MB 는 저장소에 영구히 남아 모든 clone 이 그 비용을 치른다.
압축하면 12MB 다. 적재 코드가 `.gz` 를 투명하게 읽으므로 푸는 작업은 필요 없다.

| `CCTV정보.csv.gz` | data.go.kr 전국 CCTV(`1741000/cctv_info`) | 2026-06-29 | 375,224 | 249,597 | 2026-05-15 ~ 06-26 |

**행 수 ≠ 지점 수.** CCTV 는 한 지점에 카메라 여러 대면 행이 나뉘어 있어 좌표 중복이 12.6만 건이다.
안전 점수는 지점 밀도를 세므로 적재할 때 좌표로 중복을 제거한다.

## 갱신하는 법

평소에는 갱신할 필요가 없다 — 변경분은 API 증분이 가져온다.

CSV 를 새로 받아야 할 때(원천 스키마 변경, 대량 정정 등)만 이 절차를 쓴다.

```bash
# 1) 포털에서 CSV 를 내려받아 backend/data/ 에 둔다
# 2) 압축해서 이 폴더로
gzip -9 -c "backend/data/<파일>.csv" > "backend/data/source/<파일>.csv.gz"
# 3) 위 표의 받은 날·행 수·갱신시점 범위를 다시 재서 갱신한다
# 4) 압축 안 한 원본은 커밋하지 않는다(.gitignore 의 *.csv 가 막는다)
```

## 왜 원본(.csv)은 커밋하지 않나

`backend/.gitignore` 의 `*.csv` 가 막는다. 압축본(`.gz`)만 예외로 추적한다 —
원본을 실수로 넣으면 8배 큰 파일이 히스토리에 영구히 박힌다.

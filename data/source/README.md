# 원천 CSV 원장

이 디렉터리는 공공데이터포털 등에서 받은 안심시설 원본 CSV를 보관합니다. 이 문서는 보관 중인 파일과 실측 품질,
새 판을 받았을 때의 절차를 다룹니다.

서버는 이 디렉터리의 CSV를 직접 적재하지 않습니다(관리자 업로드로 일원화, 2026-10-11). 여기 있는 파일은 관리자
CSV 화면의 원본 목록과 미리보기(`SafetySpotCsvFileStore`)와 출처 추적에 쓰이고, 실제 적재는 관리자 화면에서 같은
파일을 업로드해 이뤄집니다. 적재 흐름 전체는 [`docs/DATA_STORAGE.md`](../../docs/DATA_STORAGE.md)를 참고합니다.

파일은 gzip으로 저장합니다. 원본 합계 약 105MB는 저장소 히스토리에 영구히 남아 모든 clone이 그 비용을 치르지만,
압축하면 약 12MB입니다. 관리자 CSV 미리보기와 업로드가 `.gz`를 바로 읽으므로 풀어 둘 필요가 없습니다.

### CCTV와 비상벨은 API와 같은 판입니다

실측 때 행 수가 API `totalCount`와 정확히 일치했습니다(377,278 / 88,634).

### 보안등은 좌표를 주는 지자체가 일부뿐입니다

전국이 1,839,475건인데 CSV는 50,000행(7개 지자체)입니다. 처음에는 포털 상한에 잘렸다고 봤지만, 실측 결과 좌표를
올린 지자체가 일부뿐이라는 더 근본적인 문제가 있었습니다.

| 지자체                                 | 좌표 보유율 |
|----------------------------------------|------------:|
| 창녕군, 김해시, 평창군, 함양군, 증평군 |        100% |
| 여주시                                 |         97% |
| 양산시                                 |         27% |
| 서울 마포구(API 실측)                  |          0% |

- 서울 마포구는 표본 100건 중 좌표 0건, 주소는 100%였습니다.
- 자치구마다 좌표 품질이 다릅니다. 마포구는 0%(주소만)이지만 서초구와 관악구는 100%입니다. 전량 표본 1,000건의
  좌표 보유율은 100%였으므로, 서울에 좌표가 없다는 초기 판단은 마포구 하나로 일반화한 오판이었습니다.
- 결손 목록은 bueongi-service 저장소의 `docs/lamp-missing-districts.md`에 있습니다. 전국 195개 중 188개에 보안등이
  없습니다(서울은 24개 자치구 전부).
- `제공기관코드`가 곧 API의 `insttCode`입니다(창녕군 10,041건 일치). 지역 단위 수집이 가능합니다.

업로드할 때 좌표 없는 행은 건너뜁니다. 업로드에 없는 자치단체는 경로 요청 때 보안등 API로 자치단체 단위 지연
적재를 합니다([`docs/EXTERNAL_SERVICES.md`](../../docs/EXTERNAL_SERVICES.md)). 주소를 지오코딩해 채우는 방식은
구현되지 않았습니다.

### 지자체 개별 보안등 CSV

전국 표준데이터 API에 합류하지 않은 지자체는 개별 CSV를 받아 `lamp/`에 넣습니다.

| 파일                                     |  행 수 | 좌표 | 비고                           |
|------------------------------------------|-------:|-----:|--------------------------------|
| `lamp/경상남도_고성군_보안등정보.csv.gz` | 10,054 | 100% | API는 9,284건을 주지만 좌표 0% |
| `lamp/경상북도_칠곡군_보안등정보.csv.gz` |    496 | 100% | API는 0건                      |

인코딩은 원천마다 다릅니다. 전국 표준데이터는 CP949, 지자체 개별 파일은 UTF-8(BOM)입니다. 읽는 쪽이 앞부분을 보고
자동 판별합니다.

## 행 수와 지점 수

CCTV는 한 지점에 카메라가 여러 대면 행이 나뉘어 있어 좌표 중복이 12.6만 건입니다. 안전 점수는 지점 밀도를 세므로
적재할 때 좌표로 중복을 제거합니다.

## 새 판을 받았을 때

1. 포털에서 CSV를 받아 관리자 화면에서 해당 종류로 업로드합니다. `.gz`도 그대로 올릴 수 있습니다. 보안등처럼 파일이
   여럿인 종류는 [`docs/DATA_STORAGE.md`](../../docs/DATA_STORAGE.md)의 반영 절차를 따릅니다.
2. 같은 파일을 압축해 이 폴더에 보관합니다.

   ```bash
   gzip -9 -c "<파일>.csv" > "data/source/<종류>/<파일>.csv.gz"
   ```

3. 위 표의 행 수, 지점 수와 갱신 범위를 다시 재서 고칩니다.
4. 압축하지 않은 원본은 커밋하지 않습니다.

## 원본 CSV를 커밋하지 않는 이유

저장소 `.gitignore`의 `*.csv`가 원본을 막고, `.csv.gz`는 막지 않아 압축본만 추적됩니다. 원본을 실수로 넣으면 약
8배 큰 파일이 히스토리에 영구히 남습니다.

> 선행: `efd7283` CCTV 적재를 방범 성격 설치목적구분만으로 필터링

## 1. 필터 후 재검증 (실데이터)

검증 방식: 실 `backend/CCTV정보.csv`(375,220행)에 대해 **필터 전/후 파서**로 인덱스를 구성하고,
`SafetyScorer`가 실제로 쓰는 `GridSpatialIndex.withinCorridor(path, 30m)` 쿼리로 비교(키·서버 불요).

### 총 적재
| | 건수 |
|---|---|
| 필터 전(목적 무시) | 375,220 |
| 필터 후(방범만) | **315,459** |
| 제외 | 59,761 (**15.9%**) |

→ 비방범(교통단속·시설물관리·재난재해·쓰레기단속·교통정보수집·기타)이 제거됨. 분포 분석치(15.5%)와 일치(+0.4%p는 후행 콤마로 목적 불확실한 0.5% 보수적 제외분).

### 샘플 서울 경로 corridor 30m 내 CCTV (전 → 후)
| 경로 | 전 | 후 |
|---|---|---|
| 강남역→역삼역 | 2 | 1 |
| 시청→광화문 | 8 | 6 |
| 홍대입구→합정 | 4 | **0** |
| 신촌→이대 | 9 | 5 |

→ 실 경로의 방범 CCTV만 남도록 정상 동작. 일부 구간(예: 홍대입구→합정)은 기존 CCTV가 전부 비방범이라 0이 됨.
**유의**: 해당 구간 안전점수가 하락 — 이는 과대평가 교정(정확도 향상)이나, 점수 분포가 바뀌므로 UX상 인지 필요.

## 2. CCTV 소스: API vs 파일(CSV) 분석

### 현재 구조
- **실 소스 = CSV**(`backend/CCTV정보.csv`, 375,220행, CP949, 75MB). 백엔드가 `useLines`로 스트리밍 적재.
  data.go.kr 키 지연으로 사실상 단일 소스.
- **API 경로 = 거의 비활성**. 파이프라인(B-1)이 data.go.kr→`cdn/cctv/{sigungu}.json` 생성 설계이나,
  키 미활성으로 `cdn/cctv`엔 시드 3건(11110/11680)만 존재. 백엔드는 CSV(375k)+JSON(3) merge.

### 비교
| 항목 | 파일(CSV) | API(data.go.kr) |
|---|---|---|
| **설치목적구분(용도)** | ✅ 포함 → 방범 필터 가능 | ⚠️ 표준데이터(15013094)엔 존재하나 파이프라인 `keyColumns`에 **미매핑**. live `cctv_info` 조회서비스 필드 노출은 키 활성 후 확인 필요 |
| 최신성 | 스냅샷(수동 재다운로드, 노후화) | 호출 시점 최신(월 cadence 자동 갱신 가능) |
| 완전성 | 전국 375k 일괄 | 페이지네이션·쿼터·부분수집 처리 필요 |
| 키 의존 | 없음(현재 동작 중) | data.go.kr 키 필수(현재 미활성) |
| 적재 비용 | 75MB·37만 startup 스트리밍(결정론) | 파이프라인이 cdn JSON으로 선처리 → 백엔드 startup 저렴 |
| 운영 | 75MB 비커밋·수동 갱신 | 키관리·엔드포인트 안정성, 단 스케줄 자동화 가능 |
| 장애내성 | 외부 무관 | data.go.kr 가용성 의존 |

### 결론 / 권고
- **지금은 CSV가 더 효율적이고 더 유능**: 키 없이 동작 + 유일하게 **설치목적구분 보유** → 방금의 방범 필터를 가능케 함.
  API 경로는 현재 purpose를 안 가져오므로 활성화돼도 같은 필터를 못 해 **비방범 CCTV가 다시 섞일 위험**.
- **중장기 = 하이브리드**: data.go.kr 키 활성 시
  1) 파이프라인 B-1 `keyColumns`에 `purpose: "설치목적구분"` 추가, 출력 JSON에 용도 포함
  2) **파이프라인 단계에서 동일 방범 필터 적용**(파일/API 양 경로 일관성 보장)
  3) `cdn/cctv/{sigungu}.json` 선생성·월 1회 자동 갱신 → 백엔드 startup 경량화
  4) CSV는 키 부재/장애 시 폴백·부트스트랩으로 유지
- 즉 **데이터 소스는 점진적으로 API(최신성·자동화)**, 단 **방범 필터를 파이프라인으로 끌어올려** 두 경로가 어긋나지 않게 하는 것이 핵심.
